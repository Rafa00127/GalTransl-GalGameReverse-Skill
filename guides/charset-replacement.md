# 首选路线：把引擎读取的字符集改成 GBK/UTF-8

中文入库有三条路线，**先试本页这条**。只有在确认加载路径不支持目标编码、或改造代价明显不合理时，才退回[脚本层改编码](#路线二脚本层换编码)或 [JIS 代理映射](jis-substitution.md)。

| 顺序 | 路线 | 代价 | 结果 |
|---|---|---|---|
| 1（首选） | 改引擎读文本的字符集为 GBK/UTF-8（真汉化），同步重建字库与 UI | 补丁点较多，字库要一起改 | 不需要注入器、不需要转区，字体统一 |
| 2 | 脚本层整体改用引擎已支持的编码 | 需实测加载路径；长度/指针/配套表跟着改 | 视引擎而定 |
| 3（兜底） | 保持 CP932 + JIS 代理映射 + hook/替换字体 | 需要注入器、常需转区、字体不统一、UI 易乱码 | 快速救急 |

不是所有引擎都走 1：字库或文本解码全部由不可改的第三方库/资源决定时，2 或 3 更现实。**先证明"字符串字节从哪进来、字模从哪出去"，再选路线。**

## 路线一需要同时打通的五条链

一条没打通就会出现"正文正常、UI 乱码"或"部分字显示成方框"这类半成品。逐条定位、逐条验证：

1. **读取编码**：把字节解释成字符的位置。常见形态：字符集常量（如 `DX_CHARSET_*`、`CHARSET_GB2312`）、`CreateFontA` 的 `charset` 参数、`MultiByteToWideChar`/`WideCharToMultiByte` 的 `CodePage`、引擎自建的表和常量、注册表/配置文件里的默认代码页。
2. **双字节判定**：决定"哪两个字节算一个字"。若引擎自建 SJIS 判定表就跟着改；若它调系统 API（中文系统上就是 GBK 语义），通常不用动，但**必须实测**，不要凭系统区域推断。
3. **主字库**：点阵/纹理槽位公式 = 基址 + 组宽 × (lead - 起始) + (trail - 起始)。改编码时 lead/trail 范围、组宽、槽数、槽大小要一起重算；重算后检查生成量（GBK 要覆盖的汉字远多于 SJIS）与启动耗时。
4. **备用/小字号字库**：不少引擎另有一条在启动时用系统 GDI 把字渲染进内存缓冲的链路（右键菜单、顶栏、存读档对话框常走这条）。**分配、预生成、取字三处必须一起改**，只改一端会越界崩溃或画不出字；跳过区间时要换成"不跳过"而不是无条件跳转，否则可能死循环。改完用内存读取把点阵打成字符图核对。
5. **UI 定长字符串槽**：exe/二进制资源里的界面文字多是定长槽。中文必须**等长或更短 + NUL 补齐**，并断言文件长度不变；禁止变长切片赋值（会把缓冲区撑大、后面全部移位、程序报废）。已经为绕字库而改成英文的条目，字库改好后要换回中文。

另外：**代码区/指令区绝不转码**。只改被标记为显示文本的字段；同一段字节若同时被正文和资源指令引用，按引用隔离修改。玩家名、变量、控制符等占位符原样保留。

## 做成幂等补丁

- 每个补丁点一个脚本，默认 dry-run，`--apply` 才写；写入后断言文件长度、校验和与预期一致。
- 逐点记录"原字节 → 新字节 → 依据"。重复执行应报 "已应用" 或 MISMATCH，而不是重复叠加。
- 一次只改一个变量并重新验证；多条链同时改会让崩溃原因无法归因。

## 与脚本回填的关系

本页只解决"引擎怎么读、怎么画"。剧本本身仍按引擎页回填：先确认新的存储编码（GBK/UTF-8 的字节宽度与原来不同），再更新长度、指针、跳转、字符串池与校验。**编码改为 GBK 不等于可以把任意长度塞进定长字段**，容量规则仍按格式。

## 验证清单

| 阶段 | 必查 |
|---|---|
| 离线 | 补丁后文件长度不变、字节 diff 只落在预期位置、重跑幂等 |
| 启动 | 不崩、不黑屏、进入标题与开场 |
| 正文 | 对白、旁白、姓名、选项、章节标题、换行与分页 |
| 字库 | 生僻字、常用字、标点、半角字符；主字库与备用字库分别看 |
| UI | 顶栏、右键/系统菜单、对话框按钮、确认框、存档列表标题 |
| 交互 | 存/读档、改名、设置界面 |
| 边界 | 未翻译的原文、控制符、占位符、旧存档 |

离线往返与"能解出可读中文"都不等于显示正常；正文通过也不代表备用字库通过。交付时分别说明已验证/未验证项。

## 何时退回兜底

- 文本解码在不可修改的第三方组件里，或字符集由资源而非代码决定；
- 字库不可重建（压缩/加密/工具缺失），而专用替换字体可行；
- 只是想快速验证翻译文本，暂不做引擎改造。

退回 [JIS 代理映射](jis-substitution.md) 时，**只保留一条路线**：要么 hook 还原字符，要么专用替换字体，不要互相叠加，也不要和已经改成 GBK 的补丁混用。
